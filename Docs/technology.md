# Tecnologías

- PHP 8.4 y Laravel 13.
- Inertia 3 y Vue 3.
- CoreUI Free 5 como CSS/Sass; sin componentes `@coreui/vue`.
- Vite 8.
- SQLite para desarrollo inicial.
- PostgreSQL como candidato para despliegue.
- PWA responsive como objetivo posterior.

No se usa Tailwind para evitar duplicar resets y utilidades.
