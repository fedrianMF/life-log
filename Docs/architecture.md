# Arquitectura

- Monolito Laravel modular.
- Rutas Laravel y páginas Vue mediante Inertia.
- Sin API interna mientras no exista otro consumidor.
- PostgreSQL como base de datos en desarrollo y producción.
- Línea de tiempo común con detalles tipados por módulo.
- Métricas importantes en columnas; JSON solo para experimentos.

No crear abstracciones antes de tener un caso real.
