# Mejoras futuras

## Calidad

- Añadir Larastan cuando exista suficiente código de dominio.
- Añadir ESLint cuando crezca la lógica de Vue.
- Definir cobertura mínima cuando la suite sea representativa.

## Automatización y seguridad

- Activar Dependabot después de confirmar los lockfiles.
- Evaluar CodeQL cuando aumente el código o haya contribuciones externas.

Incorporar cada control solo cuando aporte una señal útil y mantenible.
